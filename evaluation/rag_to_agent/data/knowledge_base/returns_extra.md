# 星桥优选模拟扩展知识库

以下规则均为本项目构造的虚构测试资料，并非真实商家承诺。

## 退货凭证
因商品破损申请售后时需提交商品照片及外包装照片。

## 换货库存
换货申请受目标规格库存影响；缺货时需改为退款或等待人工处理。

## 退款渠道
退款只原路退回原支付渠道，不支持更换收款账户。

## 赠品退回
主商品退货时须一并寄回对应赠品；赠品丢失须先联系人工客服。

## 取消售后申请
售后申请尚未审核时可在售后页撤销；进入寄回阶段后需联系人工客服。

## 错发商品
错发商品由商家承担寄回运费，用户应保留外包装和面单照片。

## 退货进度
售后页展示申请、审核、寄回、验收和退款五个状态；知识库不能查询某订单的实时状态。

## 超期争议
超过无理由退货期限后，如主张质量问题，仍可提交凭证交由人工核实。
