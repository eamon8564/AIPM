# 星桥优选退款与退货政策

## 期限与条件

商品可在签收次日起 7 个自然日内申请无理由退货，期限不从付款日计算。商品须保持完好，配件、赠品和原包装齐全，不影响二次销售。

定制刻字商品不支持无理由退货；质量问题不受该例外限制，但须提交照片并由人工客服核实。

## 退货流程与运费

用户在订单页面提交退货退款申请。审核通过后，应在 5 个自然日内寄回并填写运单号。非质量问题的寄回运费由买家承担；质量问题或错发由商家承担，报销上限每单 15 元。

## 退款到账

仓库验收通过后 2 个工作日内发起退款，原路退回；支付渠道预计 1～3 个工作日到账。该时效不代表任何具体订单已经退款。

## Agent 操作边界

Agent 可以判断模拟订单的退货资格，但创建售后工单属于有副作用操作，必须获得用户明确确认后才能执行。
